# Pixuleizar ♡

A tiny cozy browser game made as a playable love letter.

## Run it

Open `index.html` in a browser. No build step or dependencies are required.

## Controls

- **WASD / Arrow keys** — walk
- **Space / Enter** — interact / continue dialogue
- Find all **5 hearts** to unlock the ending.

## Art direction

The game uses a hand-drawn, storybook-inspired top-down look: chunky silhouettes, layered foliage, warm dirt paths, timber framing, tiny flowers, and a dense cozy forest village.

The art is generated procedurally in Canvas so the project stays lightweight and dependency-free. It is intentionally a prototype; custom sprite sheets can be dropped in later for a richer pixel-art finish.
